# Import and Export

A bronze bust on a plinth in a gallery, made in Blender 5.2 by `import-export.py` (`blender -b --factory-startup -P
import-export.py`) and opened here with Blender's own reader.

- **The asset.** `bust.glb`, written by Blender's glTF 2.0 exporter: the bust's mesh with its Bronze and Marble
  materials, its origin at the bottom of its foot.
- **Import.** Set the 3D cursor on the plinth, then File > Import > glTF 2.0 (.glb/.gltf) and choose bust.glb. OBJ,
  PLY, STL and FBX import the same way.
- **Export.** File > Export > glTF 2.0, Wavefront (.obj), Stanford PLY (.ply), STL (.stl) or FBX: the options, then
  where to save.

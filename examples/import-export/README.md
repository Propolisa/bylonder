# Import and Export

Suzanne brought in by File > Import > Wavefront (.obj), made in Blender 5.2 by `import-export.py` (`blender -b
--factory-startup -P import-export.py`) and opened here with Blender's own reader.

- **Files.** `suzanne.obj` and `suzanne.mtl`, written by Blender's OBJ exporter: Suzanne with its UV map, a color
  attribute, smooth shading and the Skin material.
- **Import.** File > Import > Wavefront (.obj), choose both files, check the options and click Import Wavefront OBJ.
  Stanford PLY, STL and FBX import the same way.
- **Export.** File > Export > Wavefront (.obj), Stanford PLY (.ply) or STL (.stl): the options, then where to save.

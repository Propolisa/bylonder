# Nonlinear Animation

A box animated by three actions layered as strips, made in Blender 5.2 by `nla.py` (`blender -b --factory-startup -P
nla.py`) and opened here with Blender's own reader.

- **Tracks.** Slide moves the box across the ground; Hop, repeated three times, adds a hop on top; Turn, from frame 49,
  combines a quarter turn at half influence.
- **Editing.** Open the Nonlinear Animation editor, click a strip and press N for its properties (blending, influence,
  repeat). Tab enters tweak mode to edit the strip's action; key a new action and push it down with the button beside
  it.

# 2D Animation

Blender 5.2's 2D Animation application template, as File > New > 2D Animation opens it in Blender: its `startup.blend`
(from `scripts/startup/bl_app_templates_system/2D_Animation`), read with Blender's own reader.

- **Workspaces.** 2D Animation (the 3D Viewport over the Dope Sheet, the Outliner and the Properties editor) and 2D Full
  Canvas, both in Draw Mode.
- **Scene.** A camera at 1920 x 1080 and a Grease Pencil object with the Lines and Fills layers and the template's materials (Solid Stroke,
  Solid Fill, Dots Stroke, Squares Stroke).
- **Drawing.** Press Numpad 0 to look through the camera and draw with the Pencil brush; the asset shelf and the tool
  header hold Blender's brushes and their settings.

# Texture Paint

Made in Blender 5.2 by `texture-paint.py` (`blender -b --factory-startup -P texture-paint.py`) and opened here with
Blender's own reader.

- **Suzanne.** Unwrapped with Smart UV Project; its material's Image Texture (a 512 x 512 image packed into the file)
  feeds Principled BSDF's Base Color. Open the Texture Paint workspace to paint on it in the 3D Viewport or the Image
  Editor, or UV Editing to see and edit its UVs.
- **Sphere.** A color attribute, red at the top to blue at the bottom; Vertex Paint Mode shows and paints it.

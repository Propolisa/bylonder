# Robot Arm

A workshop robot arm reaching for a brass gear at night, made by `robot-arm.py` in Blender. The arm is one mesh skinned
to the Arm Rig armature (Base, Lower Arm, Upper Arm, Head); its work light is parented to the Head bone. Select the
rig, switch to Pose Mode and rotate the bones to aim the arm: the pool of light on the bench follows.
